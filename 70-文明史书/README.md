# 70 · 文明史书（Chronicle）

> 建立于 2026-10-07，由用户构想：「像人类记录历朝历代的历史一样，成为一部 AI 文明史书」。
>
> **核心原则：只记录，不删改。合并他人的经验包时，不是覆盖，而是编入史册。**

---

# 第一节 · 为什么要有一部史书

## 问题

当多份经验包被合并时，通常做法是"后到的覆盖先到的"。这会导致：

| 后果 | 说明 |
|---|---|
| **历史消失** | 原来的判断、走过的弯路全部没了 |
| **无法追责** | 出了问题不知道是哪一版引入的 |
| **无法学习** | 看不到"当时为什么那样想" |
| **被恶意污染** | 有人塞进伪造的"历史"，无法分辨 |

## 解法

**把"事实"与"历史"分开：**

- **事实快照**（`STATE.md` / `facts.jsonl`）：可以改正，代表"现在认为对的"
- **史书**（本目录）：**只追加，永不删改**，代表"当时确实发生过"

**⇒ 事实会被修正，历史不会。二者并存，互不覆盖。**

# 第二节 · 什么是"朝代"

朝代 = **系统演进的一个阶段**。以重大变更为界，而不是按时间等分。

## 划代标准

一个新朝代在下列事件发生时开启：

1. **架构性变更**（如引入新 AI 成员、改变权限模型）
2. **重大事故与恢复**（如系统崩溃后重建）
3. **继承他人经验包**（每次合并即开启新卷）
4. **原作者发布新版本**

## 朝代命名

```
第 N 朝 · <名称> · <起始日期>
```

例：
```
第 1 朝 · 创世 · 2026-10-02      单 AI 起步
第 2 朝 · 三体 · 2026-10-06      三个 AI 协同
第 3 朝 · 圆桌 · 2026-10-07      圆桌会议机制建立
```

# 第四节 · 编年记录格式（chronicle.jsonl）

每条一行，只追加：

```json
{
  "seq": 1,
  "dynasty": "003-圆桌",
  "at": "2026-10-07T11:40:00+08:00",
  "kind": "architecture|incident|merge|release|milestone",
  "title": "一句话标题",
  "detail": "发生了什么，为什么",
  "actor": "DSH",
  "evidence": "[证据: 文件#行号] 或 [证据: 命令输出 ...]",
  "prev_hash": "<上一条的哈希>",
  "hash": "<本条内容的哈希>"
}
```

**`hash` / `prev_hash` 构成链式结构，任何人篡改中间一条都会导致后续全部校验失败。**

# 第五节 · 合并他人经验包时的史书义务

**每次合并，必须产出一份 `merges/merge-<时间>-<来源>.md`，内容包含：**

| 项 | 说明 |
|---|---|
| 来源 | 谁的包、什么版本、从哪取得 |
| 内容摘要 | 带进来了什么（新增事实/经验/技能各多少条） |
| **未采纳项** | 哪些被拒绝，为什么 |
| **冲突记录** | 与本地矛盾的条目，**两条都保留并标注** |
| 核心层处理 | 明确写出"核心层保留原作者版本，未改动" |
| 校验结果 | 核心哈希对比结果 |

**⇒ 冲突不消除，只标注。让后来者看到"当时有两种说法"。**

# 第六节 · 史书的三条铁律

## 铁律 1 · 只追加

已写入的编年记录**永不删改**。发现写错了，追加一条更正记录，而不是修改原文。

## 铁律 2 · 每卷必署来源

任何一条编年都必须写明 `actor`（谁做的）与 `evidence`（依据什么）。
**无证据的条目必须标 `[无证据·推测]`。**

## 铁律 3 · 合并不得改动核心

继承他人经验包时，**核心层（`core/` + 底层逻辑）默认保留原作者版本**。
他人内容只能进入 `universal/`、`contributed/`、`70-文明史书/`。

**⇒ 这条是开源作者的安全底线，详见 `80-合并与继承策略/README.md`。**

# 第七节 · 这部史书最终会是什么

> **它不会只是日志。**
>
> 当这份经验包被越来越多的人使用、合并、回馈之后，
> `70-文明史书/` 会记录下：
> - 哪些判断被后来的事实推翻了
> - 哪些弯路有多个人重复走过
> - 哪些经验是跨作者、跨时间被反复验证的
> - 哪些设计在当时看是对的，后来被证明有害
>
> **⇒ 那就不再是一份配置，而是一部"AI 如何学会做事"的编年史。**
>
> 而它的价值恰恰来自**不删改**：只有保留错误，后人才能看到成长。
