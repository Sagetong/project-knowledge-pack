# 受保护层 · core\

> **本目录属于受保护层。需用虎符解锁后才能访问。**

## 这里放什么

- `security.json`  安全策略（公开什么、保护什么）
- `keys\`          各类密钥（如需要）
- `config.json`    核心参数

## 为什么加密

这些内容不属于"可分享的知识"，而是"你的私有配置"。
泄露不会让别人学会什么，但会暴露你的环境信息。

## 怎么访问

```powershell
cd ..\30-工具\tally
.\unlock.ps1              # 输入口令 + 提供 tally.key
# 内容会释放到 ..\WORK\core\
```
