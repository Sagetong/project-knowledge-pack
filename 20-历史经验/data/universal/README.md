# universal —— 通用知识

> **这个命名空间里的内容应该在任何环境下都成立，是可以分享出去的部分。**

## 放什么

- 抽象出的方法论（"网络问题先开日志，不要推理"）
- 跨环境成立的技术事实（"Reality 的 dest 不能走 CDN"）
- 可复用的判断准则
- 工具层面的通用技巧

## 不放什么

- 任何具体 IP / 路径 / 主机名 / 凭据
- 只在特定版本成立的临时信息（用 facts.expires 标注）

## 怎么进入这里

**有两种方式：**

1. 从 `local` 提升（`promote.ps1`）—— 经历了实际验证
2. 直接写入（`harvest.ps1 -Namespace universal`）—— 一开始就确定通用

**推荐方式 1** —— 先在真实场景验证，再抽象。

## 校验要求

本命名空间的每条内容都应通过敏感信息扫描（无 IP / 路径 / 密钥）。
