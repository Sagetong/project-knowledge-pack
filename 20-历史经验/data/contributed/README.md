# contributed —— 外部贡献（隔离区）

> 状态：**机制已就绪，等待第一批贡献**
> 最后核验：2026-10-07 15:52

## 这一层是干什么的

```
外部经验 = 未验证 = 可能有误 = 不能直接影响决策
```

**所以外部经验先进这个隔离区，经过验证后才提升到 `universal`。**

## 怎么写入（已实测可用）

```powershell
.\30-工具\memory.ps1 add-lesson `
    -Title "标题" -Kind technique `
    -Context "..." -Mistake "..." -Solution "..." -Reusable "..." `
    -Namespace contributed
```

**支持的命名空间：`local` / `universal` / `contributed`（默认 `local`）**

## 一个曾经存在的缺陷（已修）

**2026-10-07 发现：`memory.ps1` 原本**没有** `-Namespace` 参数。**

**后果：**
```
文档写着"用 -Namespace contributed 写入"
    ↓
但参数根本不存在
    ↓
PowerShell 没有报错
    ↓
记录【静默写进了 local】
```

**⇒ 也就是说：这一层以前是"文档上有、实际没通"。**

**现在已加参数并实测验证：写入 `contributed` 时 `local` 不再受影响。**
